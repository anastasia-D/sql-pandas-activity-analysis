# Анализ событий с SQL и pandas

Учебный проект по анализу событий в SQLite. В ноутбуке использую SQL для отбора данных и построения витрины, а pandas — для просмотра результатов и расчёта корреляции.

- Фильтрую записи с помощью `SELECT`, `WHERE` и подзапросов.
- Объединяю таблицы через `LEFT JOIN`, нахожу первые события и рассчитываю отклонение от срока в часах.
- С помощью `GROUP BY`, `HAVING` и `CASE` сравниваю группы и показатели до и после первого просмотра.

[Открыть ноутбук с примерами строк и результатами](activity_analysis.ipynb)

## Данные

Исходный учебный анализ опирался на журналы просмотров и проверок задач. В этой версии скрипт `demo_data.py` создаёт синтетические записи в памяти SQLite. Результаты в ноутбуке рассчитаны на этих записях. Сравнение групп носит описательный характер.

## Запуск в Linux или WSL

Проверено на Python 3.12. Выполните команды из папки проекта.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
jupyter lab activity_analysis.ipynb
```

Чтобы повторить расчёты, выполните ячейки ноутбука по порядку.
